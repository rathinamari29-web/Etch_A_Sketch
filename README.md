# Etch-a-Sketch 🎨

A dynamic, browser-based sketchpad inspired by the classic Etch A Sketch toy. This project allows users to draw on a customizable grid using various color modes and grid dimensions.

---

## ✨ Features

- **Custom Grid Sizing:** Adjust the canvas dimensions dynamically (e.g., 16x16, 32x32, 64x64).
- **Multiple Drawing Modes:**
  - **Classic:** Monochromatic drawing (black/dark pencil).
  - **Rainbow:** Generates random RGB colors on hover or click-drag.
  - **Eraser:** Clears individual tiles back to the default background.
- **Clear Canvas:** One-click reset to wipe the current canvas clean.
- **Responsive Layout:** Clean, centered interface optimized for desktop browsers.

---

## 🛠️ Built With

- **HTML5:** Semantic layout and control panel structure.
- **CSS3:** Flexbox/CSS Grid styling, button states, and hover effects.
- **JavaScript (ES6):** DOM manipulation, event listeners (`mouseover`, `mousedown`), and dynamic grid generation.
